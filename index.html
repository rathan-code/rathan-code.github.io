🎯 What is opencl-api-cpp?

opencl-api-cpp is a magical helper that makes your computer's graphics card (GPU) work for you. Imagine being able to tell your GPU to do heavy calculations, process images, or run complex simulations - all with simple, easy-to-understand code instead of the complicated stuff that usually comes with GPU programming.

Think of it as a translator between you and your GPU. You write simple English-like commands, and opencl-api-cpp converts them into the special language your graphics card understands. It's perfect for people who want to create fast, powerful applications without spending weeks learning difficult programming concepts.

💡 See How Simple It Is

Here's a tiny example of what you can do. This simple code adds two lists of numbers together using your GPU:

#include "opencl_api.hpp"

// Create two lists of numbers
std::vector<int> a = {1, 2, 3, 4, 5};
std::vector<int> b = {10, 20, 30, 40, 50};

// Add them together using GPU power
auto result = opencl::add(a, b);

// result now contains: {11, 22, 33, 44, 55}
